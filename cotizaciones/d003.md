## 1. Introducción

El presente proyecto propone la creación de un ecosistema de integración personalizado para automatizar el ciclo de facturación. Este desarrollo se caracterizará por la utilización de un **Middleware Híbrido** que combina la flexibilidad de **n8n** con la potencia y seguridad de scripts **PHP en Backend**, garantizando un procesamiento de datos exacto según las normativas del SAT (CFDI 4.0).

## 2. Objetivo

Eliminar la carga administrativa manual mediante el desarrollo de un puente digital que capture eventos de **Synchroteam**, procese la lógica de negocio en un servidor privado y ejecute el timbrado fiscal en **Facturama** de forma autónoma.

---

## 3. Arquitectura del Proyecto (Qué se realizará)

Se entregará una estructura de software organizada en puntos de conexión (endpoints) en un servidor que consta de:

- **Webhook Middleware (PHP):** Un receptor de alta disponibilidad diseñado para escuchar las notificaciones de Synchroteam, validar la integridad de los datos y filtrar ruidos de red.
- **Core Backend (PHP):** Procesador lógico encargado de mapear impuestos, manejar excepciones y transformar los datos en estandard de notacion Javascript (JSON) de origen al formato requerido por el SAT (CFDI 4.0).
- **Orquestador (n8n):** Gestión del flujo de trabajo, reintentos automáticos y conectividad entre servicios.
- **Capa de Documentación:** Carpeta técnica con el código fuente comentado y manual de despliegue.

## 5. Entregables y Alcance

**Entregables:**

1. **Carpeta de Código Fuente:** Scripts PHP documentados (Webhook y Middleware).
2. **Flujo integrador por medio de un servidor n8n:** Archivo JSON de respaldo de la automatización.
3. **Documentación Técnica:** Guía de campos mapeados (Synchroteam ID ↔ Facturama UUID) y guía de solución de errores comunes.

**Alcance:**

- **Sincronización:** Emisión automática de factura al marcar tarea como "Finalizada".
- **Validación Fiscal:** Verificación de RFC y Código Postal antes del envío.
- **Notificación:** Envío automático del comprobante al correo del receptor.

---

## 6. Ventajas de esta Solución

1. **Propiedad Intelectual:** Al ser archivos PHP, el cliente no depende 100% de una plataforma externa; el código es suyo.
2. **Seguridad:** El procesamiento ocurre en un entorno controlado (GCP), no en servidores compartidos.
3. **Escalabilidad:** Al estar documentado, el sistema puede crecer en el futuro para incluir otros procesos (ej. inventarios o nómina).

---

## Resumen del Desarrollo

Este desarrollo proporcionará un sistema automatizado y privado que garantiza que cada tarea finalizada en Synchroteam se traduzca en una factura emitida correctamente ante el SAT que puede ser monitorizado cuando se requiera. El propósito fundamental es entregar a **Kitchen Valenzuela** una herramienta completa, propia y escalable para la automatización de su proceso de facturación.
