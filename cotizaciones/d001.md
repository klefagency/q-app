# Cotización de Desarrollo Web

## Proyecto: Grupo Publicitario - Nuevo Sitio Web Corporativo

### Descripción del Proyecto
Desarrollo de un sitio web corporativo moderno y responsivo para Grupo Publicitario, enfocado en presentar sus servicios, portafolio y métodos de contacto de manera profesional.

### Especificaciones Técnicas

| Característica | Descripción |
|----------------|-------------|
| **Tecnología** | HTML5, CSS3, JavaScript ES6+ |
| **Framework CSS** | Tailwind CSS |
| **Responsive** | Mobile-first, todas las resoluciones |
| **SEO Básico** | Meta tags, sitemap, schema markup |
| **Performance** | Lighthouse score > 90 |

### Páginas Incluidas

1. **Inicio** - Hero section, servicios destacados, CTA principal
2. **Nosotros** - Historia, equipo, valores corporativos
3. **Servicios** - Catálogo detallado de servicios
4. **Portafolio** - Galerías de proyectos con filtros
5. **Blog** - Sistema de artículos
6. **Contacto** - Formulario, información, mapa

### Desglose de Inversión

| Concepto | Costo |
|----------|-------|
| Diseño UI/UX | $20,000 MXN |
| Desarrollo Frontend | $30,000 MXN |
| Desarrollo Backend (CMS básico) | $15,000 MXN |
| SEO y Performance | $10,000 MXN |
| Hosting + Dominio (1 año) | $3,000 MXN |

### **Total: $78,000 MXN**

### Tiempo de Entrega
**6 semanas** desde el inicio del proyecto

### Incluye
